# ขอบเขตพัฒนาข้อมูลรอบถัดไป

รายการที่ผู้ใช้ย้ำให้คงไว้หลังการจัด Layer ฝั่งซ้าย:

1. คืน ThaiWater และเครื่องมือเดิมทั่วประเทศให้ครบ: ระดับน้ำ ฝน เขื่อน ขอบเขตจังหวัด/อำเภอ/ตำบล แม่น้ำ คลอง และอ่างเก็บน้ำ OSM รวมถึงตรวจพยากรณ์ 7 วันและความกดอากาศจากเว็บเดิม
2. ใช้ HatyaiClimate สำหรับภาพสถานการณ์น้ำเฉพาะจังหวัดสงขลา กรองตำแหน่งตามขอบเขตจังหวัด ไม่ถือว่าทุกจุดของเว็บรวมกล้องอยู่ในสงขลาโดยอัตโนมัติ
3. เพิ่มหมวดวิดีโอถนน HLS กรมทางหลวงในสงขลา แยกจากภาพนิ่งกล้องริมคลอง ทดสอบ playlist, media segment, CORS และเวลาภาพก่อนเปิดใช้งาน
4. เชื่อม TMD South Nowcast โดยตรงหลังยืนยันการดึงอัตโนมัติและเงื่อนไขการใช้ แยกเวลาสร้าง manifest จากเวลาตรวจวัด/พยากรณ์ และใช้ bounds ของแต่ละเฟรม

แผง Layer รอบนี้รวมข้อมูลที่เว็บมีอยู่แล้ว การ์ดพยากรณ์ SWIRLS ปัจจุบันยังรับผ่าน One Data ไม่ใช่การเชื่อม TMD South Nowcast โดยตรง ส่วนหมวดวิดีโอถนนและเครื่องมือขอบเขต/ลำน้ำยังเป็นงานรอบถัดไป
