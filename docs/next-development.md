# ชั้นข้อมูลทดลองที่เปิดใช้แล้ว

โหมดนี้ต้องเข้าสู่ระบบก่อนใช้ ดูรายละเอียดการป้องกันและการอัปเดตใน [development-access.md](development-access.md) ข้อมูลทดลองถูกย้ายออกจากไฟล์ GitHub Pages ไปยังพื้นที่ที่ตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์

หมวด **กำลังพัฒนา** มีปุ่มเปิด–ปิดข้อมูลบนแผนที่จริง ปิดหน้าต่างควบคุมแล้วเลเยอร์ยังอยู่:

- ฝนสะสม 3 ชั่วโมงและลมที่ 10 เมตรจาก Open-Meteo 8 โมเดล พร้อมเลือกเวลาและเล่นภาพ เก็บกริดตัวอย่าง 6° ครอบคลุมเอเชีย 24°E–180°E, 12°S–84°N ใช้แคช 12 ชั่วโมง ไม่อ้างว่าเป็นกริดความละเอียดดั้งเดิมของโมเดล
- CLPP / ONWR (ต้นทาง RadarGIS): ภาพตรวจวัดย้อนหลังและ Nowcast 180 นาที เก็บสำเนา PNG ตาม URL/ขอบเขตของแต่ละเฟรม แยกเอกลักษณ์แคชตามรอบออกประกาศเพื่อไม่ใช้ภาพพยากรณ์เก่าแทนตรวจวัดใหม่
- ฝนสะสมล่วงหน้า 180 นาทีรายจังหวัดครบ 77 จังหวัด แตะพื้นที่ดูค่าเฉลี่ยและสูงสุดจาก API ไม่ตีความสัดส่วนพื้นที่เป็นโอกาสฝนตก
- สถานีฝน CLPP แสดงฝน 1/24 ชั่วโมง เวลา หน่วยงาน ประเภทค่ารายงานหรืออนุมาน และแสดงสถานีข้อมูลเก่าแบบจาง ไม่แทนค่าขาดหายด้วยศูนย์
- รายจุด CLPP อ่านช่วงค่าจากสี PNG ที่เก็บไว้และระบุว่าเป็นค่าประมาณ **ไม่ได้เรียก API พยากรณ์รายจุดดิบ** เพราะ API ไม่มี CORS สำหรับ GitHub Pages ภาพโปร่งใสแสดงเป็นไม่มีสีสะท้อน/ไม่มีข้อมูล ไม่อ้างว่าฝนเป็นศูนย์
- GSMaP 5 ชั่วโมงยังปิดไว้ เพราะแหล่งภาพที่ตรวจไม่พร้อม

GitHub Actions ตรวจแหล่งข้อมูล CLPP ทุกครั้งที่เผยแพร่ (กำหนดรอบ 5 นาที อาจล่าช้าตามคิว GitHub) ส่วนแบบจำลองใช้แคช 12 ชั่วโมงเพื่อลดการเรียก API ทั้ง frontend และ popup แสดงเวลาต้นทาง/เวลาที่เก็บจริง เก็บสำเนาเริ่มต้นที่มีวันที่กำกับไว้เมื่อแหล่งข้อมูลไม่พร้อม การเผยแพร่ใช้ GitHub Pages เดิม

เครดิต: Open-Meteo และเจ้าของแต่ละโมเดล (ทั่วไป CC BY 4.0; UK Met Office CC BY-SA 4.0) แผน API ฟรีใช้สำหรับงานไม่ใช่เชิงพาณิชย์ CLPP ยังไม่พบข้อกำหนด API, rate limit หรือใบอนุญาตเผยแพร่ซ้ำที่ชัดเจน จึงระบุเป็นข้อมูลทดลองและลิงก์กลับต้นทาง

ทดสอบ Node สำหรับกริด ลม fallback การเลือกเวลา การแปลสี และฟิลด์สถานี; Python สำหรับผลรวมฝน/ทิศลม การปฏิเสธกริดไม่ครบ URL ภาพ bounds และเวลา UTC มี probe จาก GitHub Actions สำหรับ API และ PNG จริงเพิ่มเติมจาก unit tests

รายการที่ผู้ใช้ย้ำให้คงไว้หลังการจัด Layer ฝั่งซ้าย:

1. คืน ThaiWater และเครื่องมือเดิมทั่วประเทศให้ครบ: ระดับน้ำ ฝน เขื่อน ขอบเขตจังหวัด/อำเภอ/ตำบล แม่น้ำ คลอง และอ่างเก็บน้ำ OSM รวมถึงตรวจพยากรณ์ 7 วันและความกดอากาศจากเว็บเดิม
2. ใช้ HatyaiClimate สำหรับภาพสถานการณ์น้ำเฉพาะจังหวัดสงขลา กรองตำแหน่งตามขอบเขตจังหวัด ไม่ถือว่าทุกจุดของเว็บรวมกล้องอยู่ในสงขลาโดยอัตโนมัติ
3. เพิ่มหมวดวิดีโอถนน HLS กรมทางหลวงในสงขลา แยกจากภาพนิ่งกล้องริมคลอง ทดสอบ playlist, media segment, CORS และเวลาภาพก่อนเปิดใช้งาน
4. เชื่อม TMD South Nowcast โดยตรงหลังยืนยันการดึงอัตโนมัติและเงื่อนไขการใช้ แยกเวลาสร้าง manifest จากเวลาตรวจวัด/พยากรณ์ และใช้ bounds ของแต่ละเฟรม

แผง Layer รอบนี้รวมข้อมูลที่เว็บมีอยู่แล้ว การ์ดพยากรณ์ SWIRLS ปัจจุบันยังรับผ่าน One Data ไม่ใช่การเชื่อม TMD South Nowcast โดยตรง ส่วนหมวดวิดีโอถนนและเครื่องมือขอบเขต/ลำน้ำยังเป็นงานรอบถัดไป

ผล probe จาก GitHub Actions รอบพัฒนา: Open-Meteo เรียกได้ แต่ CLPP timeout ทั้ง Ubuntu และ Windows runner (ยังยืนยันสาเหตุฝั่งเครือข่ายไม่ได้) จึงไม่รับรอง CLPP สดต่อเนื่องบน Pages ในรอบนี้ ตัวเก็บข้อมูลจะลองใหม่และเผยแพร่ health.json เมื่ออัปเดตไม่สำเร็จหน้าเว็บแสดงว่าใช้สำเนาตามเวลาที่กำกับ

โมเดลทั้ง 8 ใช้เฉดฝนจากตัวอย่างเจ้าของร่วมกัน: 0.3, 2, 7, 15, 50 และ 500 มม./3 ชม. (น้ำเงิน–ฟ้า–เขียว–เหลือง–ส้ม–แดง) เก็บข้อมูล 99 ชั่วโมงและตัดเฟรมท้ายที่ต้นทางไม่เผยแพร่ออก การขยายกริดเอเชียใช้ตัวอย่าง 6° เพื่ออยู่ในโควตา API ฟรี ไม่ใช่ความละเอียดดั้งเดิมของแบบจำลอง แต่ละรอบเผยแพร่ปกติจะอัปเดตแบบจำลองที่หมดอายุไม่เกินหนึ่งชุด เพื่อคงการอัปเดตเว็บหลักให้ต่อเนื่อง
