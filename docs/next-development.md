# แบบจำลองพยากรณ์

เปิดอ่านสาธารณะตามคำขอผู้ใช้วันที่ 27 พฤศจิกายน 2569 โดยใช้ GitHub Pages เดิม ข้อมูลพยากรณ์ถูกอ่านผ่าน `/public/data/` ของเซิร์ฟเวอร์ ส่วนอัปโหลดและสำเนาดิบอื่นยังตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ ไม่มีรหัสผ่านหรือ updater token ใน JavaScript สาธารณะ

## ข้อมูลที่เปิดใช้

- Open-Meteo: ECMWF IFS HRES, GFS, ICON, UK Met Office Global, Google WeatherNext 3 (ค่าเฉลี่ย ensemble), ECMWF AIFS, JMA GSM, ARPEGE, CMA GRAPES และ Best Match รวม 10 ตัวเลือก
- ทุกโมเดลครอบคลุมกรอบสี่เหลี่ยม 82–124°E, 6°S–30°N ไม่มีหน้ากากวงรี และไม่ประมาณค่านอกกริด
- กริดแสดงผล IFS HRES และ WeatherNext 3 ระยะ 1.2° (1,116 จุดต่อโมเดล); อีก 8 ตัวเลือกใช้ 3° (195 จุดต่อโมเดล) รวม 3,792 ตำแหน่งต่อรอบ แคช 12 ชั่วโมง รวมประมาณ 7,584 ตำแหน่งต่อวัน การไล่สีไม่เพิ่มความละเอียด กริดนี้ไม่ใช่ความละเอียดต้นทาง 9/11 กม.
- ฝนเป็นอัตราเฉลี่ยช่วงก่อนหน้า 3 ชั่วโมง หน่วย mm/h; ลมเป็นค่าเฉลี่ยเวกเตอร์ช่วงเดียวกันที่ระดับ 10 เมตร เลือกช่วงครอบคลุมเวลาปัจจุบันเมื่อเริ่มใช้ หากไม่มีช่วงนั้นต้องระบุเวลาจริง
- CLPP / ONWR: เรดาร์ตรวจวัดและ Nowcast 180 นาที รวมถึงฝนสะสมคาดการณ์รายจังหวัด 77 จังหวัด ใช้ bounds และสีเรดาร์ต้นทาง เวลาเก่าหรืออัปเดตไม่สำเร็จยังมีข้อความแจ้ง

## หน้าจอ

คอมพิวเตอร์เปิด MAP LAYERS เมื่อเริ่มหน้าและคงไว้จนผู้ใช้ปิด มือถือเริ่มโดยไม่มีหน้าต่างเปิด แบบจำลองพยากรณ์เข้าถึงจากแถบเมนู ปุ่มข้างชั้นข้อมูล และแถบเครื่องมือด้านขวา หน้าต่างแบบจำลองกว้างเท่า MAP LAYERS และซ้อนบนตำแหน่งเดียวกันโดยไม่ล้างสถานะของ MAP LAYERS

ปุ่มด้านล่าง 3 ปุ่มอยู่กึ่งกลาง แถบภาพเรดาร์และแบบจำลองมีปุ่มย่อ เหลือเฉพาะเล่น/แถบเวลา/ขยายกลับ เลือกโมเดลจากแถบเวลาได้ เกณฑ์สีฝนแบบจำลองแสดงด้านล่างปุ่ม ไม่อยู่ในกล่องเล่นเวลา

GitHub Actions ตรวจแหล่งเรดาร์ทุก 5 นาทีตามคิว ส่วนแบบจำลองเก็บสำเนา 12 ชั่วโมงและทยอยอัปเดต ไม่รับประกันข้อมูลใหม่ทุก 5 นาที หากต้นทางหรือ runner ไม่พร้อมจะใช้สำเนาที่มีเวลาระบุ

เครดิต: Open-Meteo และเจ้าของโมเดล; โดยทั่วไป CC BY 4.0, UK Met Office CC BY-SA 4.0 แผน API ฟรีสำหรับงานไม่ใช่เชิงพาณิชย์ CLPP ยังไม่พบใบอนุญาตเผยแพร่ซ้ำและ rate limit ที่ระบุชัด จึงคงเครดิตและลิงก์ต้นทาง ไม่มีการอ้างว่าได้รับสิทธิ์ใหม่จากการเปลี่ยนหน้าจอเป็นสาธารณะ

MetNet Global ถูกยกเลิกตามคำขอผู้ใช้ ไม่อยู่ในรายการพัฒนา ไม่มีข้อมูลหรือเมนูของชุดนี้
