# แผนที่อากาศ Windy

เปิดจากหมวดแผนที่อากาศ หรือชั้นข้อมูลและการแสดงผล แล้วเลือกมุมมอง:

- **แผนที่เต็ม** — Windy ครอบบริเวณแผนที่ พร้อมหมุดจุดพยากรณ์
- **แผนที่ + พยากรณ์รายจุด** — เพิ่มตารางรายชั่วโมงด้านล่าง เปิด–ปิดได้ด้วยสวิตช์ตารางพยากรณ์
- **ตารางพยากรณ์อย่างเดียว** — ตารางลอยด้านล่าง โดยยังเห็นแผนที่ RMWeather

กล่องควบคุมอยู่ทางซ้าย ย่อและปิดได้ บนมือถือเริ่มแบบย่อ ส่วนหน้าเริ่มต้นเว็บไซต์ยังแสดง Positron + RainViewer + ลม โดยไม่เปิด Windy อัตโนมัติ

## ตารางบนแผนที่หลัก

ปุ่ม **การพยากรณ์ล่วงหน้า** อยู่ถัดจากปุ่ม **ภาพและเวลา** ด้านล่างแผนที่หลัก กดเพื่อเปิด–ปิดตาราง Windy โดยไม่ต้องเข้าแผนที่อากาศ เลือกตำแหน่งฉัน กลางแผนที่ หรือหาดใหญ่ได้จากหัวตาราง ขณะเปิดยังเลื่อนและซูมแผนที่หลักได้

เริ่มต้นด้วยตารางปิดอยู่ทั้งคอมพิวเตอร์และมือถือ ปิดได้ด้วยปุ่มเดิม ปุ่ม × หรือ Escape ตารางกับเครื่องเล่นภาพและเวลาจะสลับกันเปิดเพื่อไม่บังกัน เมื่อปิดจะหยุดโหลด iframe และเมื่อเปิดหมวดแผนที่อากาศจะปิดตารางบนหน้าหลักก่อน

## จุดพยากรณ์

**ตำแหน่งฉัน** ใช้ Geolocation ของเบราว์เซอร์ เมื่อเปิด Windy จะขอพิกัดใหม่ด้วย high accuracy และไม่ใช้แคช หากกำลังค้นหาจะระบุสถานะไว้ หากเข้าไม่ถึงตำแหน่งและไม่มีพิกัดเดิมจะใช้ **หาดใหญ่** เป็นจุดสำรองที่แสดงชัดเจน

ชื่อจุด พิกัด หมุด และตารางพยากรณ์ใช้พิกัดชุดเดียวกันผ่าน `lat` / `lon` และ `detailLat` / `detailLon` แสดงค่าความคลาดเคลื่อนเมื่ออุปกรณ์รายงาน เบราว์เซอร์อาจให้ตำแหน่งหยาบโดยเฉพาะคอมพิวเตอร์ที่ไม่มี GPS จึงไม่รับประกันว่าจะตรงตำแหน่งจริงทุกครั้ง

**กลางแผนที่** ใช้จุดกึ่งกลางแผนที่หลัก RMWeather ในขณะที่กดปุ่ม หากต้องการเลือกจุดเอง ให้กลับแผนที่หลัก เลื่อนแผนที่ แล้วเปิด Windy และกดปุ่มนี้ ส่วน **หาดใหญ่** เป็นพิกัดคงที่ 7.0084, 100.4767 เมื่อเลือกจุดเองแล้ว ผลค้นหาตำแหน่งที่มาทีหลังจะไม่เปลี่ยนจุดที่เลือก

พิกัดอุปกรณ์อยู่ในหน่วยความจำของหน้าเว็บและส่งให้ Windy เมื่อเปิด widget ไม่บันทึกลง repository หรือไฟล์ข้อมูลที่เผยแพร่

## ชั้นข้อมูลและแหล่งที่มา

เมนูของ RMWeather มี 12 ชั้น: เรดาร์, ดาวเทียม, ฝนและฟ้าคะนองพยากรณ์, ฝนสะสม, ลม, ลมกระโชก, อุณหภูมิ, เมฆ, ความชื้น, จุดน้ำค้าง, ทัศนวิสัย และความกดอากาศ มีชั้นเพิ่มเติมในเมนูของ Windy เอง ความพร้อมใช้งานขึ้นกับผลิตภัณฑ์และพื้นที่ของผู้ให้บริการ

ใช้ iframe ทางการ `https://embed.windy.com/embed.html` โดยตั้ง `type=map` หรือ `type=forecast` และ `detail=true` สำหรับตาราง หน่วย °C, มม. และ กม./ชม. แยกผลิตภัณฑ์เรดาร์/ดาวเทียมออกจากแบบจำลอง ECMWF ตารางรายจุดเป็นข้อมูลพยากรณ์ แม้แผนที่จะกำลังแสดงเรดาร์ตรวจวัด

ไม่ต้องเพิ่ม API key หรือ Iframely และไม่ใช้ Webcams API key แทน Point Forecast API รักษาโลโก้ Windy และลิงก์ต้นทางไว้

อ้างอิงตัวสร้าง embed ทางการ: [แผนที่](https://embed.windy.com/config/map), [ตารางพยากรณ์](https://embed.windy.com/config/forecast)

## การตรวจสอบ

`node --test tests/*.test.js` ตรวจการสร้าง URL, ผลิตภัณฑ์, จุดเดียวกันของหมุด/ตาราง, พิกัดผิดรูปแบบ, จุดสำรอง และผล GPS ที่มาทีหลัง ทดสอบ iframe จริงบนคอมพิวเตอร์ 1280×720 และมือถือ 390×844 แล้ว ทั้งเรดาร์พร้อมตาราง ตารางแยก และดาวเทียม

การทดสอบเบราว์เซอร์ใช้จุดหาดใหญ่ที่เลือกเอง การอนุญาต GPS และความแม่นยำจริงขึ้นกับอุปกรณ์ผู้ใช้
