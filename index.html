ABOUT THE DATA

ที่มาและเวลาของข้อมูล

ตรวจสอบเวลาที่กำกับแต่ละรายการ ข้อมูลเก่าหรือขาดเกณฑ์จะแสดงแยกจากสถานะปกติ ใช้ติดตามเบื้องต้น ไม่ใช่ประกาศเตือนภัยอย่างเป็นทางการ

  • One Data / PSU · ระดับน้ำ RID, อากาศ TMD, GFS และภาพเรดาร์ภาคใต้
  • HatyaiClimate และหน่วยงานเจ้าของกล้อง · ภาพ CCTV อัปเดตเป็นระยะ
  • HY-CCTV · อ้างอิงแนวทางค้นหาและดูภาพกล้อง
  • Open-Meteo · พยากรณ์อากาศ / RainViewer · เรดาร์ภาพรวม
  • Windy Webcams API · กล้องเฉพาะสงขลา แสดง Timelapse ตามเวลาที่ต้นทางกำกับ
  • Windy Embed · แผนที่อากาศ / TMD · วิดเจ็ตพยากรณ์ 7 วัน อ้างอิงแนวทางจาก Ron Weather
  • ELEMNT Cartographer, Protomaps / OpenStreetMap, Mapterhorn DEM และ GEBCO_2026 · ภูมิประเทศและภูมิประเทศใต้ทะเล
  • OpenStreetMap, Esri, OpenTopoMap และ OpenFreeMap · พื้นแผนที่และเครดิตบนแผนที่

ข้อมูล One Data อัปเดตเป็นรอบประมาณ 5 นาทีตามความพร้อมของต้นทางและ GitHub Actions เวลาโหลดไฟล์ไม่ใช่เวลาตรวจวัด
